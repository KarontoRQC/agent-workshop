# data/

> `data/` · 1 个 JSON 数据文件

## 职责

提供推荐智能体源目录。前端用它丰富英雄池、头像和启动链接，后端用它加载默认候选智能体名称。

## 文件列表

| 文件 | 用途 | 关键导出 |
|------|------|----------|
| `source_agents_full.json` | 约 60 个智能体/项目的名称、功能、类型、链接、知识库和介绍。 | `智能体名称`, `智能体链接`, `知识库` |

## 开发模式

- **新增智能体**: 保持 `智能体名称` 字段非空；如有可打开入口，填入 `智能体链接`。
- **改字段名**: 同步检查 `backend/config.py` 和 `frontend/src/lib/agentLaunchCatalog.ts`。
