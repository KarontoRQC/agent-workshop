# index.css

> `frontend/src/index.css` · CSS · 约 33 行

## 用途

定义页面根级 reset、字体、背景色、文本渲染和 `#root` 尺寸。

## 关键区域

| 区域 | 作用 |
|------|------|
| `:root` | 字体、颜色、背景和渲染设置。 |
| `body` | 去除默认 margin 并固定最小尺寸。 |
| `#root` | 让 React 应用占满视口。 |

## 依赖

内部依赖:
- `main.tsx` — 导入该文件。
